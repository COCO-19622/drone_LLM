# 8000 条训练数据扩展记录

目标文件：`C:\LLM\minimind-lzk\dataset\train.jsonl`。

在原有 2000 条基础上新增 6000 条，保持 `conversations` 字段；每条恰有一条 `user` 和一条 `assistant` 消息，消息仅含 `role` 和 `content`。原样本内容全部保留，最终顺序已打散。扩展前原文件保存在 `train.before_expand_2000.jsonl`，可用于回退与核对。

| 类别 | 原有 | 新增 | 最终 |
| --- | ---: | ---: | ---: |
| 无人机基础知识 | 700 | 2100 | 2800 |
| 自主飞行场景判断 | 600 | 1800 | 2400 |
| 任务规划与步骤分解 | 400 | 1200 | 1600 |
| PX4 / MAVLink / ROS 工程知识 | 200 | 600 | 800 |
| 通用简单指令 | 100 | 300 | 400 |
| 总计 | 2000 | 6000 | 8000 |

新增概念题基于现有基础卡和工程卡，在相关主题内组织概念区分、说明匹配与错误配对纠正；新增场景题组合两个已有情况，分别问处理、核查和恢复条件，排除了地面/飞行阶段混搭及明显互斥的定位状态；新增计划题把两个已有流程约束组合起来，保持 5～8 个步骤。通用部分补充简短算术、排序、信息提取、列表和短句处理。

这些是现有知识的合成与组合扩展，**不是新增 6000 个独立知识点或真实飞行案例**。相关主题和任务骨架仍会重复，未声称完成全部语义近似去重或专家逐条认证。后续如划分验证集，应按概念主题、故障骨架或任务骨架分组，避免组合变体泄漏到验证侧。

知识内容沿用 `C:\LLM\uav_sft` 中已读取文档的整理结果，具体来源与许可记录见该目录的 `sources.json`。`train_8000_metadata.jsonl` 中的 `source_ids` 对应该清单，`seed_refs` 对应原知识卡、场景或任务骨架。通用指令为新编写的简单任务。没有加入原始传感器日志或“传感器数据 → 电机 PWM”样本。

基本检查详见 `expansion_validation.json`；最终文件已逐行解析，空字段、完全重复样本、规范化后重复问题均为 0。抽查样本见 `expansion_review.md`。项目已有验证入口会将实际分词器和 SFT 读取器的结果写入 `C:\LLM\minimind-lzk\dataset_validation.json`，该结果与基本 JSON 检查分开记录。

扩展脚本：`C:\LLM\uav_sft\expand_to_8000.py`。它只接受原始 2000 条输入，遇到已经扩展的文件会拒绝再次覆盖。脚本不加载模型、不启动训练；本次也未修改训练参数、模型权重或已有检查点。此前完成的训练记录仍对应 2000 条版本。
